# 設計手法の組み合わせ方

[トップページ](../README.md) / [ガイド一覧](README.md) / 設計手法の組み合わせ方

複数の設計手法を一緒に使う場合は、**それぞれの手法がどんな問題を解決し、何を守るよう求めているか**を確認します。

## 組み合わせる前に確認すること

1. **それぞれを採用する目的は何か。** どんな問題を解決したいのか、手法ごとに言葉にします。
2. **同時に守れない規則はないか。** 片方が求める構造を、もう片方が禁止していないか確認します。
3. **どこに適用するのか。** プロジェクト全体なのか、一部の機能なのかを決めます。
4. **新しく何を決める必要があるか。** 処理の分割、情報の受け渡し、テスト方法など、必要になる作業を具体的に挙げます。

## 実際に導入するとき

最初から複数の手法をまとめて導入せず、各手法を個別に理解してから、対象の機能を1つ選んで試します。

導入後は、各手法の規則を守れているかだけでなく、変更する場所や処理の流れが分かりやすくなったかを確かめます。

手法の原理や規則は、必ず[個別の解説](../methods/README.md)で確認してください。
